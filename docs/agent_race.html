Granite Switch — SR vs LoRA Agent Race TELEMETRY
0:00.0

Agents switching adapters, as in the adapter benchmark's Serving Quality block. Each lane runs 16 agents, at most 8 at a time: the next one starts as soon as one finishes. Each agent has a prompt of its own, generates 512 tokens and switches adapter every 32, over 64 synthetic adapters, with tool calls and round trips as real sleeps.

lora-vllm: stock vLLM serving the adapters as LoRAs. At every switch it ends the request and starts a new one, prefilling the agent's whole context again (cached only for an adapter it served before).

gs-sr-vllm: granite-switch Shadow Residual. One generation runs until a tool call; its K/V come from the base model, so an adapter change needs no re-prefill. As in the switch benchmark, each agent keeps one adapter for its task: SR's switch is taken as free.

The lanes ran one after the other on the same GPU, each after an untimed warm-up run, and are replayed side by side.
